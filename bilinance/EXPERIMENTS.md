# BILINANCE 实验记录

> 策略迭代历史。环境: 合约 BTCUSDT, 初始 $10,000(每次全新), 本地随机行情。

## 测试 1: 合约 10x 动量 + 15s 兜底 + TP1%

**参数:** LEV=10, MARGIN=$50, TP=价格+1%, TIME_LIMIT=15s, MOMENTUM_N=3(0.5s/采样), MAX_POS=3, 时长 180s

**结果:**
- 开仓 30 次, 平仓 27 (W15/L12)
- 最终 usdt: $10,004.29 (**+$4.29, +0.04%**)
- 平均每笔: +$0.16

**观察（重要）:**
- **0 次 TP 触发**, 全部 TIME 平仓 → TP+1% 在 15s 内几乎不可达(BTC 波动不够)
- 15s 时间兜底在 BTC 上 = 随机碰运气; BTC 行情是随机趋势(trend 持续 50-220 tick ≈ 1-4 分钟)
- 手续费 0.05%/次, 30 次开仓 ~$1.3, 不是主要损耗
- W15/L12 但只赚 $4 → 盈亏比接近 1:1, TIME 平仓无优势

**结论:** 参数不适合 BTC 特性。下一步方向:
- [x] TP 降低到 0.3-0.5%(10x 下 ROE 3-5%)
- [x] 时间兜底缩短到 5-8s, 加快周转
- [ ] 或反过来: 用更长持仓(抓住趋势周期), TP 放宽 + 时间兜底 60s+
- [ ] 动量窗口加大(趋势 50-220 tick, 用 10-20s 采样)

## 测试 2: 高周转 (TP 0.4% + 6s 兜底)

**参数:** LEV=10, MARGIN=$50, TP=价格+0.4%, TIME_LIMIT=6s, MOMENTUM_N=3, MAX_POS=3, 180s

**结果:**
- 开仓 31, 平仓 29 (W18/L11, 胜率 62%)
- 最终: $10,018.08 (**+$18.08, +0.18%**)
- 比测试 1 好 4 倍 (0.04% → 0.18%)

**观察:**
- 仍然 **0 次 TP 触发**, 几乎全是 TIME 平仓(6s)
- 6s 内 BTC 波动多数在 ±0.4% 内, 0.4% 阈值仍偏高(约 1.5-2 sigma)
- 胜率 62% 但每笔赚小额(+0.1~0.3%), 靠概率堆利润
- 大部分 TIME 平仓实际在 +0.2~0.8% 区间, 说明方向判断多数正确, 只是没等到 TP

## 测试 3: 新闻冲击跟随 ⭐

**时间:** 2026-10-07 11:06
**参数:** 检测12币单秒跳变>1%, 跟随方向开合约 10x/$50, TP=价格+2%, 兜底6s, 180s

**机制依据(源码):**
- 新闻冲击: `shockDrift=mag/8×方向, shockTicks=8秒`, mag=5%~14%
- 即新闻币 8 秒内单向走 5-14%, 普通波动只有 ±0.1-0.2%/秒
- 单秒跳变 >1% 即可可靠检测冲击开始

**结果(run3):** 5 笔 W5/L0, 累计 +19.4%
```
SOL   +6.60% (1s TP)     ADA   +5.81% (1s TP)
PEPE  +5.23% (1s TP)     HAFU  +1.50% (6.6s)
NAILONG +0.31% (6.6s)
```

**关键:** 冲击方向大概率延续(8秒持续), 进场后 1-2 秒 TP 快速触发
10x 杠杆下价格 +6.6% = **66% ROE**

**观察:**
- 检测是价格跳变(非读新闻文本), 可靠且实时
- meme 币(vol 3-4)跳变频繁, 大币(BTC)少
- 开仓快路径: hash 直达合约页 + 3 次 evaluate ≈ 1.5s, 冲击 8s 来得及
- run4 复测: **4笔 W3/L1, +$35.69, 累计+11.3%**
```
ETH short +6.08%   PEPE short +4.53%   HAFU long +1.25%   HAFU short -0.60%
```
- 连续两轮正收益: run3 +19.4% / run4 +11.3%, 平均 ~+15%
- 败笔: 进场晚了冲击已结束(HAFU -0.60%), 需更快或接受滑点
