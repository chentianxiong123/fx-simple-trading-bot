# BILINANCE 实验记录

> 策略迭代历史。环境: 合约 BTCUSDT, 初始 $10,000(每次全新), 本地随机行情。

## 测试 1: 合约 10x 动量 + 15s 兜底 + TP1%

**参数:** LEV=10, MARGIN=$50, TP=价格+1%, TIME_LIMIT=15s, MOMENTUM_N=3(0.5s/采样), MAX_POS=3, 时长 180s

**结果:**
- 开仓 30 次, 平仓 27 (W15/L12)
- 最终 usdt: $10,004.29 (**+$4.29, +0.04%**)
- 平均每笔: +$0.16

**观察（重要）:**
- **0 次 TP 触发**, 全部 TIME 平仓 → TP+1% 在 15s 内几乎不可达(BTC 波动不够)
- 15s 时间兜底在 BTC 上 = 随机碰运气; BTC 行情是随机趋势(trend 持续 50-220 tick ≈ 1-4 分钟)
- 手续费 0.05%/次, 30 次开仓 ~$1.3, 不是主要损耗
- W15/L12 但只赚 $4 → 盈亏比接近 1:1, TIME 平仓无优势

**结论:** 参数不适合 BTC 特性。下一步方向:
- [ ] TP 降低到 0.3-0.5%(10x 下 ROE 3-5%)
- [ ] 时间兜底缩短到 5-8s, 加快周转
- [ ] 或反过来: 用更长持仓(抓住趋势周期), TP 放宽 + 时间兜底 60s+
- [ ] 动量窗口加大(趋势 50-220 tick, 用 10-20s 采样)
